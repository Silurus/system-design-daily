# Шпаргалка: Система счисления Base62

Краткое руководство по прямому и обратному переводу чисел в 62-ричную систему (используется для сокращения URL).

## Алфавит системы
`0-9` (0–9), `A-Z` (10–35), `a-z` (36–61). Всего **62 символа**.

---

## 💻 Функции на Python

```python
import string

ALPHABET = string.digits + string.ascii_uppercase + string.ascii_lowercase
BASE = 62

def encode_base62(num: int) -> str:
    """Прямой перевод: Число (ID) -> Короткий код"""
    if num == 0:
        return ALPHABET[0]
    arr = []
    while num:
        num, rem = divmod(num, BASE)
        arr.append(ALPHABET[rem])
    return ''.join(reversed(arr))

def decode_base62(string_code: str) -> int:
    """Обратный перевод: Короткий код -> Число (ID)"""
    num = 0
    for char in string_code:
        num = num * BASE + ALPHABET.index(char)
    return num
```

## 🧮 Математический пример: Код "WZD"

### 1. Прямой перевод (Деление с остатком)
Переводим `ID = 125191` в Base62:
* $125191 / 62 = 2019$, остаток **13** ($
→$ `D`)
* $2019 / 62 = 32$, остаток **35** ($
→$ `Z`)
* $32 / 62 = 0$, остаток **32** ($
→$ `W`)

Собираем остатки снизу вверх: **`WZD`**.

### 2. Обратный перевод (Схема Горнера)
Вместо вычисления степеней в лоб ($32 \cdot 62^2 + 35 \cdot 62^1 + 13 \cdot 62^0$), код использует **схему Горнера** — последовательный сдвиг разрядов слева направо.

**Пошаговый процесс в цикле (для "WZD"):**
1. **Старт:** `num = 0`
2. **Символ 'W'** (значение 32):  
   `num = 0 * 62 + 32` $
→$ **32**
3. **Символ 'Z'** (значение 35):  
   `num = 32 * 62 + 35` $
→$ **2019**
4. **Символ 'D'** (значение 13):  
   `num = 2019 * 62 + 13` $
→$ **125191**

### 🧠 Почему это работает?
Если раскрыть все скобки финального выражения, мы получим классическую формулу разложения по степеням:
$$\text{ID} = ((32) \cdot 62 + 35) \cdot 62 + 13 = 32 \cdot 62^2 + 35 \cdot 62^1 + 13 \cdot 62^0 = 125191$$
Компьютер считает этот результат за 3 простых умножения и 3 сложения, не выполняя операцию возведения в степень.
