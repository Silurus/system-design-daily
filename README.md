# System Design Daily

Ежедневный разбор одной темы по System Design. Уровень: собеседование Senior.

## Формат занятия
1. Короткая теория с примером из реальной системы.
2. Вопросы и обсуждение в диалоге.
3. Задача по теме — если есть желание её решать.
4. Конспект фиксируется в `topics/NN-slug.md`.

## Структура конспекта
- **Суть** — что это и зачем, в 3–5 предложениях.
- **Как работает** — ключевые механизмы.
- **Trade-offs** — что выигрываем и чем платим.
- **Схема** — Mermaid-диаграмма.
- **Пример** — где применяется в реальных системах.
